# English Daily

一对一 / 小班英语家教用的每日练习平台：老师出题、布置，学生每天作答、看反馈、订正。

当前是**第一期**，实现了阅读的完整闭环。功能框架见 `mermaid-diagram.png`，操作流程见 `阅读与听力转述操作手册.md`。

## 第一期功能

| 模块 | 内容 |
|---|---|
| 账号与权限 | 首次打开时初始化教师账号；老师创建、停用学生账号，可重置密码；所有人都能自己修改密码 |
| 精选题库 | 四步编辑器：1 阅读内容 → 2 题目 → 3 答案与解析 → 4 发布；分草稿和已发布；可试做、复制、删除 |
| 题型 | 单项选择、填空（含语篇填空，可设多个答案）、表达题（老师评分） |
| AI 出题 | “生成题目草稿”的结果先预览，点“确认替换当前题目”才生效；也可以“复制当前提示词”给外部 AI 用 |
| 批量导入 | 粘贴 `<questions>` 区块后“解析并预览”；粘贴 `<solutions>` 区块后“匹配并填入”。答案写 A/B/C/D 或选项全文都可以；会检查中文引号、重复题号、选项不足、答案不在选项中，每次 1–30 题 |
| AI 配置中心 | 填接口地址、模型、密钥（只存在服务器上），有测试连接；可以调整“阅读 · 辅助出题”的题目数、难度、考查点和提示词 |
| 每日作业 | 可一次选多名学生、多个日期、多份材料；布置时保存材料快照，之后改题库不影响已布置的作业；按周查看，可撤回 |
| 学生作答 | 正文在上，题目在下；可按题号切换，也可展开全部；可调字号。作答自动保存，网络失败时先存在本机，下次打开提示恢复 |
| 判分与反馈 | 客观题自动判分；答案按设置在提交后或批改后开放；老师可逐题批注、写评语、要求订正；学生端显示新反馈提醒，可标记“我已看过反馈” |
| 订正 | 只能改首次做错的题，并写订正说明；订正过程中不显示答案，提交后才开放。首次答案和成绩会保留 |

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev          # 前端 http://localhost:5173，接口 http://localhost:8787
```

第一次打开会要求创建教师账号。想直接用演示数据试的话：

```bash
SEED_DEMO=1 npm run dev:api   # 空数据库时写入演示账号：teacher / lihua，密码 demo123
```

## 部署

```bash
npm run build && npm start    # 默认端口 8787，数据保存在 ./data
```

或者用 Docker：

```bash
docker compose up -d          # 数据挂载在 ./data
```

环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口 |
| `DATA_DIR` | `./data` | SQLite 数据库所在目录 |
| `APP_TIMEZONE` | `Asia/Shanghai` | 用来判断“今天”有哪些作业 |
| `SEED_DEMO` | 不设置 | 设为 `1` 时，空数据库首次启动会写入演示数据 |

建议：

- 服务器在大陆的话，网站需要先完成 ICP 备案；香港或海外的轻量服务器不需要备案。
- 一定要配置 HTTPS（例如在前面放一层 Caddy 或 Nginx），否则密码和 API 密钥会以明文传输。
- **备份**：把 `data/english-daily.db` 复制出来就是完整备份，最好定时做。

## AI 配置

在“AI 配置中心”填写兼容 OpenAI 协议的接口，例如：

| 服务商 | API 地址 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

模型名称请以服务商文档为准。接口地址填 `mock` 会用本地模拟输出，不需要密钥，适合先熟悉流程。

## 浏览器演示版

```bash
npm run build:demo   # 生成 dist-demo/english-daily-demo.html
```

演示版把后端和 SQLite（sql.js 纯 JS 版本）都放在浏览器里运行，数据只保存在当前浏览器，AI 使用模拟输出。

## 开发

```bash
npm test             # 接口与判分、导入逻辑的测试
npm run typecheck
```

目录结构：

```
src/shared/   前后端共用：类型、判分、批量导入解析、提示词
src/server/   接口（Hono）、数据库、AI 调用、演示数据
src/node/     Node 启动入口
src/web/      前端（React）
src/demo/     浏览器演示版入口
tests/        测试
```
